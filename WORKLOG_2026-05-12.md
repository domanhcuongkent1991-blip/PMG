## Quy tac van hanh moi

- Khi owner giao task sua code va da chap thuan phuong an, AI duoc tu dong chay:
  - `npm run workflow:task-start -- -Name "<ten task ngan>"`
- Sau khi sua code, verify va commit chinh thuc, AI duoc tu dong chay:
  - `npm run workflow:task-finish`
- Neu task chua co commit chinh thuc hoac repo con dirty, checkpoint se duoc giu lai voi trang thai `HELD`.
- Neu task da co commit chinh thuc va repo sach, checkpoint tam se tu xoa.
- Kiem tra checkpoint con ton:
  - `npm run workflow:task-checkpoints`
